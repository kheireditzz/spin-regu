# 🎡 SPIN REGU · White Minimalist Edition

Aplikasi Web Roda Putar Undian (Lucky Wheel) responsif modern bertema White / Clean Light Theme.

## ✨ Fitur Utama
- **Multi-Ronde (Ronde 1 & Ronde 2)**:
  - **Ronde 1**: Regu A, Regu B, Regu C
  - **Ronde 2**: Regu A, Regu B, Regu C
- **Tema White Minimalis**: Tampilan bersih, kontras presisi, modern glass & bento surfaces, dan **Zero Emoji** (menggunakan SVG vector icons).
- **Fisika Putaran Realistis**: Smooth cubic easing out, deteksi tabrakan segmen jarum, dan animasi pointer responsif.
- **Efek Suara Sintetis (Web Audio API)**: Suara ketukan (ticking) saat berputar dan fanfar kemenangan tanpa dependensi file audio eksternal.
- **Konfeti Pemenang**: Animasi perayaan pemenang dengan canvas-confetti.
- **Kontrol Fleksibel**:
  - Opsi auto-eliminasi regu pemenang.
  - Reset ronde & reset total.
  - Riwayat lengkap hasil putaran.
  - Shortcut keyboard (Spacebar untuk putar).

## 🚀 Deployment
Deploy instan ke Vercel dan sinkronisasi otomatis dengan GitHub.
